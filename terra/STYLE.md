## 一、UI 风格总览

### 1. 核心风格定义
- **风格定位**：极简科技风 / 赛博极简 / 暗色数据可视化界面
- **适用场景**：呼吸/冥想、专注工具、数据监测、地质防灾、智能控制类应用
- **关键词**：深色模式、高对比度、低饱和主色、无多余装饰、线条利落、科技感粒子动画

### 2. 设计理念
- 以**深色为基底**，弱化干扰，突出核心动画与数据
- 界面元素采用**扁平化、直角或微圆角**设计，减少视觉噪音
- 所有交互控件保持统一的视觉语言，保证信息层级清晰

## 二、视觉规范详解

### 1. 色彩系统

| 类型 | 色值 | 说明 |
| :--- | :--- | :--- |
| 主背景色 | `#0f1720` / `#121a24` | 极深的藏青色，作为全局背景 |
| 面板背景色 | `#131d29` / `#1a2533` | 比主背景稍亮，用于侧边栏、卡片 |
| 边框/分割线 | `#1e2a3a` | 低对比度深灰蓝，用于区分区域 |
| 主色（科技青蓝） | `#4a7fb8` | 按钮高亮、强调文字、动画主色 |
| 辅助色1（橄榄绿） | `#6b8e6e` | 状态/模式切换 |
| 辅助色2（暗红） | `#993333` | 预警/异常状态 |
| 辅助色3（暖黄） | `#e6b84e` | 提示/次要强调 |
| 文本-主色 | `#e0e6ed` | 正文、标题文字 |
| 文本-次要色 | `#8899aa` | 辅助说明、标签文字 |
| 文本-禁用/占位 | `#556677` | 占位符、次要信息 |

### 2. 排版规范

- **字体**：无衬线字体（`Segoe UI`, `PingFang SC`, `Microsoft YaHei`, sans-serif），无衬线保证科技感与易读性
- **字号层级**：
  - 大标题：`28px-36px`（如“吸气”）
  - 主标题：`20px-26px`（如“静息”）
  - 正文/按钮文字：`12px-16px`
  - 辅助/说明文字：`10px-12px`
- **字重**：标题使用 `500-600`，正文使用 `400`，辅助文字常规
- **对齐**：左侧面板文字左对齐，中央数据居中对齐，右侧面板左对齐，整体统一

### 3. 组件样式规范

#### 按钮
- **基础样式**：
  - 背景：`#1e2a3a`
  - 文字：`#e0e6ed`
  - 边框：无或 1px 同色系边框
  - 圆角：`4px`（微圆角，无过度圆润）
  - 内边距：水平 `10-12px`，垂直 `6px`
- **激活状态**：
  - 背景：主色 `#4a7fb8`
  - 文字：`#ffffff`
- **大按钮（如“开始”）**：
  - 背景：面板背景色 `#131d29`
  - 边框：1px 主色 `#4a7fb8`
  - 文字：`#ffffff`
  - 内边距：`12px` 垂直

#### 滑块（Range Input）
- **轨道**：背景 `#1e2a3a`，高度 `4px`，圆角 `2px`
- **滑块**：白色圆形，宽高 `12px`，无额外样式
- **禁用默认样式**：移除原生滑块外观，统一风格

#### 输入框
- 背景：`#1e2a3a`
- 边框：无
- 文字：`#e0e6ed`
- 占位符：`#556677`
- 内边距：`10px`
- 圆角：`4px`

#### 卡片/面板
- 背景：`#131d29`
- 边框：1px `#1e2a3a`
- 无阴影，靠背景色区分层级
- 内边距：`20px`

## 三、布局规范

1.  **三栏式布局**：
    - 左侧控制面板：固定宽度 `300px`
    - 中央主画布区：弹性宽度（`flex:1`）
    - 右侧任务面板：固定宽度 `280px`
2.  **绝对定位元素**：
    - 顶部计时器：`position: absolute; top:20px; left:20px;`
    - 底部视觉模式按钮：`position: absolute; bottom:20px; left:50%; transform: translateX(-50%);`
3.  **响应式适配**：
    - 主画布使用 `resize` 事件动态调整尺寸
    - 整体布局在小屏幕下可转为堆叠式

---

## 四、动画与交互规范

1.  **核心动画**：Canvas 粒子/流体动画
    - 主色为 `#4a7fb8`，带透明度渐变
    - 有拖尾效果（通过半透明背景重绘实现）
    - 可根据呼吸节奏/心跳状态改变粒子密度与高亮
2.  **按钮交互**：点击切换 `active` 类，背景与文字颜色变化
3.  **滑块交互**：可绑定事件控制动画参数（柔度、湍流、色调、速率）

## 五、CSS 核心代码片段（可直接复用）

```css
/* 全局重置 */
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
    font-family: 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif;
}

/* 深色模式基础 */
body {
    background-color: #0f1720;
    color: #e0e6ed;
}

/* 侧边面板 */
.side-panel {
    background-color: #131d29;
    border: 1px solid #1e2a3a;
}

/* 按钮样式 */
.btn {
    background-color: #1e2a3a;
    color: #e0e6ed;
    border: none;
    padding: 6px 12px;
    border-radius: 4px;
    font-size: 12px;
    cursor: pointer;
}
.btn.active {
    background-color: #4a7fb8;
    color: #fff;
}

/* 滑块样式 */
input[type="range"] {
    width: 100%;
    background: #1e2a3a;
    height: 4px;
    border-radius: 2px;
    outline: none;
    -webkit-appearance: none;
}
input[type="range"]::-webkit-slider-thumb {
    -webkit-appearance: none;
    width: 12px;
    height: 12px;
    border-radius: 50%;
    background: #fff;
    cursor: pointer;
}
```
