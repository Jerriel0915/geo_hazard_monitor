# 报告报表模块设计文档

## 概述

开发 `web/src/views/report/` 下三个功能页面：监测报告、查询中心、数据分析。前端先行使用 mock 数据开发，后续对接后端 API。

---

## 一、监测报告 (Report.vue)

### 页面结构

参考 Device.vue 的搜索-表格-分页模式。

### 搜索栏

| 字段     | 组件            | 说明                          |
|----------|----------------|-------------------------------|
| 关键字   | el-input       | 搜索报告标题                  |
| 报告类型 | el-select      | 周报 / 月报                   |
| 时间范围 | el-date-picker | type="daterange"              |
| 操作     | el-button      | 搜索 / 重置                   |

### 表格列

| 列名     | 字段           | 说明                              |
|----------|----------------|-----------------------------------|
| 报告编号 | id             | 自增编号                          |
| 报告标题 | title          | 如"2026年第22周边坡监测周报"      |
| 报告类型 | type           | Tag标签区分 周报(蓝) / 月报(绿)  |
| 报告周期 | periodStart/End| 起止日期                          |
| 生成时间 | createTime     | 系统自动生成时间                  |
| 操作     | -              | 查看 / 下载PDF / 删除            |

无新增按钮。

### 查看弹窗

- 大对话框 (`width="900px"`)
- 顶部显示报告标题和基本信息
- 内容区域用 `v-html` 渲染富文本
- 底部操作栏：打印（`window.print()`）、导出PDF（html2canvas + jsPDF）

### 新增依赖

- `html2canvas` — 将 HTML 区域转为 canvas
- `jspdf` — 将 canvas 导出为 PDF 文件

## 二、查询中心 (Query.vue)

### 搜索条件（级联筛选）

| 字段     | 组件       | 说明                                        |
|----------|-----------|---------------------------------------------|
| 隐患点   | el-select | 选择后过滤下级的设备类型                     |
| 设备类型 | el-select | 根据选中隐患点过滤可选项                     |
| 设备     | el-select | 根据选中设备类型过滤可选项                   |
| 监测属性 | el-select | 根据选中设备过滤可选项，支持多选             |
| 时间范围 | el-date-picker | type="datetimerange"                   |
| 操作     | el-button | 查询 / 重置                                 |

### 表格（动态列）

- 基础固定列：`时间`、`设备名称`
- 动态列：根据选中的设备类型生成对应属性列
  - 例：位移计 → X方向位移、Y方向位移、Z方向位移
  - 例：雨量计 → 降雨量
- 标准分页

### CSV 导出

- 前端纯 JS 实现，将表格数据拼接为 CSV 字符串
- 使用 `Blob` + `URL.createObjectURL` 触发下载
- 无需额外依赖

## 三、数据分析 (Analysis.vue)

### 模式选择页面（初始状态）

- 页面居中展示两个大卡片按钮，水平排列
- **关联分析卡片**：图标 + "关联分析" + 描述"将多个传感器属性叠加在同一坐标系中，对比分析不同指标的变化趋势与关联关系"
- **数据宫格卡片**：图标 + "数据宫格" + 描述"以九宫格模式同时查看多个传感器的独立数据图表，快速纵览整体监测态势"
- 卡片悬停效果，点击进入对应模式

### 模式内公共元素

- 左上角 `← 返回` 按钮，回到模式选择页面

### 模式一：关联分析

**布局**：左侧面板 + 右侧图表区

**左侧面板**：
- "添加传感器"按钮 → 弹窗选择隐患点→设备→属性
- 已添加传感器以 Tag 形式展示，可删除、可设颜色
- 时间范围选择器
- 分析工具按钮组

**右侧图表区**：
- ECharts 折线图，横轴为时间
- 每个传感器属性一个系列，多 Y 轴自动分配
- 支持缩放（dataZoom）
- 右上角导出图片按钮（ECharts `getDataURL()`）

**分析工具**：
- **统计指标**：面板展示各系列的最大值、最小值、平均值、标准差
- **趋势分析**：叠加线性拟合线（最小二乘法）
- **变化率**：展示变化率曲线（当前值-前值）/前值

### 模式二：数据宫格

**布局**：
- 顶部统一时间范围选择器
- CSS Grid 3×3 九宫格，每格独立 ECharts 迷你图表
- 每格显示传感器属性名 + 折线图
- 空格子显示"添加图表"占位，点击弹出选择设备+属性弹窗
- 已配置格子点击可修改或清除
