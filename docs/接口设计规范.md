# 接口基础规范
## 请求方式
 - 查询：GET
 - 新增：POST
 - 修改：PUT
 - 删除：DELETE
## 路径规范
小写 + 中横线，按模块划分
 - /api/hazard/disasters/page
 - /api/monitor/sensors/list
 - /api/warning/records/publish
## 公共请求头
 - Authorization: Bearer {token}
 - Content-Type: application/json
## 版本控制
 - /api/v1/xxx
# 统一返回格式（强制）
所有接口必须返回统一结构，前端可全局解析处理

```json
 {
  "code": 200,          // 200成功 00>异常 401未登录
  "msg": "操作成功",
  "data": {},           // 业务数据
  "timestamp": 1735689213000
 }
```
状态码定义
 - 200 成功
 - 400 参数错误
 - 401 未登录 / Token 过期
 - 403 无权限
 - 404 接口不存在
 - 500 服务器异常
 - 601 预警触发
 - 602 设备离线
# 分页请求规范
 ## 分页参数（GET/POST）
 - pageNum=1&pageSize=10
## 分页返回
```json
 {
  "code": 200,
  "msg": "成功",
  "data": {
    "total": 128,
    "rows": [],
    "pageNum": 1,
    "pageSize": 10
  },
  "timestamp": 1735689213000
 }
```

# 接口参数校验规范
 - 非空：@NotBlank @NotNull
 - 长度：@Length(max=128)
 - 数值范围：@Min @Max
 - 格式：@Pattern 手机号、设备编号

# 接口安全规范
 - Token 鉴权，有效期 2 小时
 - 敏感接口（删除、发布预警）日志记录
 - 接口防重放：时间戳 + sign
 - 监测数据接口支持 IP 白名单
