## 通用模型规范

分为主题和报文

### 主题规范

```
sys/v1/{device_code}/{sensor_no}/updata
其中，{device_code}为设备ID，{sensor_no}为传感器编号
{updata}为数据上报
```

### 报文结构样例

```
{
    "version": "1.0",
    "deviceId": "123456",
    "sensorNo": "10010",
    "timestamp": 1694502400000,
    "data": {
        "time": 1694502400000,
        "value": 25.5
    }
}
说明：
- version：协议版本，固定值为1.0
- timestamp：数据上报时间戳，单位为毫秒
- data：数据内容，包含time和value两个字段，time为数据上报时间戳，value为数据值
```
