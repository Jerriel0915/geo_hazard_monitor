0 总览

从设备 PUBLISH 一条 MQTT 报文,到前端收到 SSE 告警推送,跨越 4 个 Maven 模块,经历「接入鉴权 → 解析富化 → Redis Stream 缓冲 → 4 阶段入库 → 双优先级判据 → 多通道分发」六步。

zwei-iot-broker zwei-iot-parser zwei-iot-timeseries zwei-iot-alarm zwei-common (事件契约) 正常路径 退避重试 失败/死信 Spring 事件
架构主轴: 事件驱动 + Redis Stream 异步缓冲。同进程内通过 ApplicationEventPublisher 发布事件解耦模块;解析与入库之间通过 Redis Stream stream:monitor:ingest 解耦速率;告警引擎监听落库事件被动触发评估,告警分发再以事件触发,广播到 SSE/短信/邮件。

7 关键数据结构演化

数据从原始字节到 SSE JSON,形态经历了 6 次转换。下表对应「业务流转图」每一跳。

阶段类型关键字段位置
原始报文 byte[] (协议二进制 / JSON 字节) MQTT PUBLISH payload
主题元信息 MonitorTopic (record) sourceType(sys/gb), deviceCode, sensorCode com.zwei.iot.parser.support
解析策略 DataParseStrategy sourceType, scriptCode(Groovy), appScope, status com.zwei.iot.parser.domain
解析后报文 ParsedMessage deviceCode, sensorCode, sourceType, dataTime, receiveTime, payloadHash(SHA-256), properties[] com.zwei.common.domain
属性运行时值 PropertyValue identifier, name, unit, value(Object), quality(0=正常) com.zwei.common.domain
标准化时序点 StandardMeasurementPoint deviceId, sensorId, sensorCode, attrCode, attrName, unit, dataTime, value, quality, reportTime, receiveTime, sourceType, payloadHash com.zwei.iot.timeseries.domain
告警判据 AlarmCriteria monitorTypeId, monitorContentId, hazardPointId(NULL=兜底), levelConfig(JSON), persistCount, silencePeriod, isEnabled com.zwei.iot.alarm.domain
等级配置 LevelConfig logicOperator(AND/OR), conditions[], groups[], groupLogic, persistCount, silencePeriod com.zwei.iot.alarm.domain
告警记录 AlarmRecord hazardPointId, deviceId, sensorId, monitorContentId, alarmLevel(1-4), alarmType(THRESHOLD/COMPREHENSIVE), criteriaId/strategyId, currentValue, triggerCount, status(1-4) com.zwei.iot.alarm.domain
通知记录 AlarmNotification alarmId, dispatchRuleId, recipientId, channel, title, content, status(1-5), sendTime com.zwei.iot.alarm.domain
SSE 推送 Map<String,Object> (事件名: alarm) alarmId, hazardPointId, alarmLevel, alarmType, alarmMessage SseEmitter.event().data()
