# 系统图标规范
系统中使用的监测图标都引用public\jc-icon中的图标。
## 文件夹划分规则
1、gray文件夹下的为灰色图标，表示离线状态。
2、green文件夹下为绿色图标，表示设备正常运行，在线监测中。
3、red文件夹下为红色图标，表示设备出现异常。
4、repair文件夹为维修图标，表示设备正在维修。
## 图标命名规则
图标的命名规则，用下划线分段隔开，每段有不同的意义，主要是监测内容、类型和用途：
1、第一段，一般是类型，对应监测内容规范，有如下几种：
   - bsw：表面水平位移
   - ssw：深部水平位移
   - bc：表面沉降
   - qj：倾角
   - lf：裂缝
   - jy：降雨量
   - dw：地下水水位
   - ky：孔隙水压力
   - tl：土压力
   - sy：渗透压力
   - th：土体含水率
   - wd：温度
   - jsd：加速度
   - sc：深部沉降
   - ls：形变-拉伸
   - ys：形变-压缩
   - nq：形变-挠曲
   - zl：轴力
   - wj：弯矩
   - zzl：自振频率
   - gnss：表面位移（GNSS）
   - sp：视频
   - nw：泥水位
   - dx：断线
   - sg：声光
2、第二段，是颜色或用途区分，主要是gray、green、red、repair，意义对应文件夹划分规则。
3、第三段，系统中的用途，有map就表示在地图上绘制；如果没有，就表示其他作为标签显示。
