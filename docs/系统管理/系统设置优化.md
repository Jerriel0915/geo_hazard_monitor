# 告警分发优化
系统管理的系统设备中告警分发，新增和编辑告警规则界面优化：
1、新增中可以支持多个隐患点选择，确定后，按隐患点列表进行循环保存；但编辑中隐患点不支持多选。
2、将类型告警和离线，改为监测告警和设备离线通知两种。
3、类型选择为监测告警后，表单项调整为告警等级、通知人员、通知渠道；类型选择为设备离线通知后，表单项调整为设备（可以多选）、通知人员、通知渠道、执行时间（频率+时间）。其中设备可以支持多选，时间可以用逗号隔开的多个时间点。
告警等级有四级，分别是：四级(注意)、三级(警示)、二级(警戒)、一级(警报)。
4、状态和备注与选择类型无关。
5、通知渠道只有三种，分别是：短信、邮件、系统消息（默认通知渠道，包括PC端和移动端的系统消息）。
