# 设备管理进行优化
## 对物联网中设备管理进行优化
1、删除设备类型、ip地址、mac地址、设备型号、安装位置、生成厂商属性；编辑时加入运行状态、最近上报时间。
2、新增设备图标，默认显示传感器列表中的第一个传感器图标，用户可以选择指定使用哪个传感器图标。
3、设备关联隐患点，是需要处理设备与隐患点关联问题和设备在隐患点区域的位置问题：
- 单设备，选择隐患点后，需要进入地图为每个隐患点指定设备安装坐标位置；
- 多设备绑定， 选择需要绑定的设备，再选择隐患点后，需要进入地图为每个隐患点指定每个设备在其中安装坐标位置；
在设备管理这个环节绑定隐患点不是必填项。重新设计新增界面。
4、复制的操作方式，改为打开新增页面，将表格选中的设备信息进行自动填写（表的唯一值不填写）；人工审核、提交；名称默认使用原名称+“复制1”。
5、传感器录入时，界面带入设备基本信息（例如：编号、名称）；传感器属性中不需要监测内容，可以根据选点的监测类型，展示指标类型的重要信息（例如：属性名、指标类型、范围）。
6、一个传感器对应一个监测类型，一个监测类型有多个属性，每个属性都可以设置初始值，并带出属性的单位。
生成过程中有疑问的请澄清。

# 基础管理中的隐患点管理优化
## 隐患点新增
1、新增界面的分组选择，没有全部，默认为未分组。
2、隐患点范围，采用显示隐患点中心坐标方式，点击小图标，弹出地图，用户可以在地图上绘制隐患点的范围，调整中心坐标,绘制隐患点灾害发生走向等。
3、去除风险等级、海拔、详细地址、位置描述属性。
## 绚定设备
绑定设备，采用左右穿梭框风格，分为待绑定设备列表和已绑定设备列表；两个设备列表中都支持设备、传感器名称模糊查询，列表中以树状显示设备和传感器，并用小图标显示设备已绑定次数；用监测类型小图标颜色显示设备和传感器运行状态;用户可以在待绑定和已绑定之间自由选择穿梭设备。
## 告警配置
告警配置弹窗中，包括告警判据、通知分发维护两部分。
1、告警判据参考 告警判据列表.png 列表功能和效果，具体规则维护参考 告警判据修改.png 中的功能和效果。
2、通知分发参考 通知分发列表.png 列表功能和效果，具体规则维护参考 通知规则-告警.png 和 通知规则-状态.png 两种功能和效果。
## 查看隐患点详情
查看弹窗中，包括隐患点详细的基本信息、绑定设备、告警配置、通知分发、监测数据等，但不允许编辑。
## 隐患点状态操作
隐患点管理中增加状态操作，可以对单个或多个隐患点进行停测/恢复、完结操作；其中操作意义：
1、停测/恢复:是对隐患点监测业务的暂停、恢复，主要在系统上不预警、不自动化报告、不在全息面板中显示等，但能继续接收监测数据和历史监测数据查询等；
2、完结:是对隐患点监测业务的结束，数据只在隐患点管理中可查，其他实时监测模块均不能显示，终止监测数据接收和处理等。

## 告警配置
弹窗只包含告警判据、通知分发维护两部分。其他隐患点基础信息、绑定设备页签删除。
