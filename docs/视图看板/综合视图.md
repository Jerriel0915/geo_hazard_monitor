# 综合视图-细化描述
## 左侧栏目
### 系统健康度
- 总体健康指数 95% 
- 健康度算法说明，用问号图标表示，单击图标弹窗展示算法描述。
- 分项分值，包括设备资料登记率、隐患点资料完善率、隐患点设备在线率、设备状态正常率、告警事件及时响应率（首次告警1小时内响应）、边坡稳定率（最近上一个月未有效告警隐患点/总隐患点数）。
### 资源情况
- 资源总数，系统中所有资源数量；
- 设备总数，分监测类型数量（包括视频设备）；
- 隐患点总数，监测中隐患点数量；
## 右侧栏目
### 设备在线状态
只统计设备状态为正常的设备，报修中的设备不参与统计。
- 设备当前在线率，显示总设备在线率，再显示在线设备总数和设备总数；使用柱状图分监测类型，显示在线数量和总数据。
- 历史在线趋势，按下午2-3点获取当天设备在线，显示最近一周的设备在线曲线；参与统计的是设备状态为正常设备。 离线设备数量，系统中所有离线设备数量；
### 告警态势
- 待办告警（突出显示），历史告警；
- 四色告警等级分组统计数量，并使用红、黄、橙、绿四种颜色表示。
- 实时告警事件列表，只包含待办告警，按告警事件倒排序展示。

## 中间栏目
### 隐患点分布图
利用卫星影像地图做隐患点分布图，标准正常监测中的隐患坐标。
- 告警，当隐患点存在待办报警时，用红色图标表示。
- 点击隐患点，中下部浮现监测曲线展示窗，与隐患点中监测数据功能相同。
- 地图基本功能，包括缩放、拖拽等。
