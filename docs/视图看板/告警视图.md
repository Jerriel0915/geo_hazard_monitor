# 告警视图-实现
分为上下结构，上部是今日新增告警统计；下部分是统计图表进行展示。
## 上部分
告警模型告警统计，今日新增告警统计。
按告警等级分为四项：红色告警（报警级），橙色告警（警戒级），黄色告警（警示级），蓝色告警（注意级）。
按图标+文字+统计数量，进行分项展示。
## 下部分
分为四个方面进行统计展示。
### 近一个月新增情况
利用echarts曲线图方式，分四个等级和合计（四个等级合计），根据告警事件发生时间，按天统计告警事件数量，进行展示。
只统计当前起过去1个月的告警数量。
### 隐患点告警列表
分隐患点名称、告警时间、告警等级、是否响应，按告警时间倒序进行展示，最近50个告警事件。
### 隐患点、预警等级一览表
使用表格方式展示，需要展示隐患点/告警等级、红色告警、橙色告警、黄色告警、蓝色告警、合计列。
需要统计监测状态中的隐患点，根据隐患点开展监测时间倒排序，分等级展示。
### 告警等级统计
使用环状图，中间显示告警总数，环上分等级展示告警数量，并使用不同颜色表示不同等级，方便查看占比。


# 优化调整
全息看板中告警视图，整体采用浅色底风格，字体显示深色。告警统计标题与告警等级现实一行，标题显示中间，前面放红色告警、橙色告警。
