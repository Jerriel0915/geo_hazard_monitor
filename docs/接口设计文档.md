# 地质灾害监测预警系统 - 后端接口设计文档

## 一、接口基础规范

### 1.1 请求方式
| 操作类型 | HTTP方法 |
|---------|---------|
| 查询 | GET |
| 新增 | POST |
| 修改 | PUT |
| 删除 | DELETE |
| 批量操作 | POST |

### 1.2 路径规范
- 基础路径: `/api/v1`
- 模块划分: `/api/v1/{模块}/{资源}/{动作}`
- 示例:
  - `/api/v1/basic/hazard-points/page`
  - `/api/v1/iot/devices/list`
  - `/api/v1/alarm/records/publish`

### 1.3 公共请求头
```
Authorization: Bearer {token}
Content-Type: application/json
X-Request-Id: {uuid}
```

### 1.4 统一返回格式
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {},
  "timestamp": 1735689213000
}
```

### 1.5 状态码定义
| 状态码 | 含义 |
|-------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录/Token过期 |
| 403 | 无权限 |
| 404 | 接口不存在/资源不存在 |
| 500 | 服务器异常 |
| 601 | 预警触发 |
| 602 | 设备离线 |

### 1.6 分页规范
**请求参数:**
- `pageNum`: 当前页码，默认1
- `pageSize`: 每页条数，默认10
- `orderBy`: 排序字段
- `order`: 排序方式(asc/desc)

**响应格式:**
```json
{
  "code": 200,
  "msg": "成功",
  "data": {
    "total": 128,
    "rows": [],
    "pageNum": 1,
    "pageSize": 10,
    "pages": 13
  },
  "timestamp": 1735689213000
}
```
