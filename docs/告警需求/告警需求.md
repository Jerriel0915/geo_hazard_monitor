# 实时告警需求
待办告警模块主要负责实时告警的接收、查询、展示和处理。
平台中，预警分为阈值预警、综合预警，新警情产生后，系统会推送系统消息和短信通知对应人员。有权限的用户可以查看当前单位下所有项目的实时告警信息，处置相关警情。

该模块表格信息包括：
- 选择
- 隐患点名称
- 告警等级
- 首次告警时间
- 最后告警时间
- 告警次数
- 告警类型
- 警情状态
- 响应人员
- 响应时间
- 操作（查看、反馈、误报、销警）

表格中按最后告警时间倒排序，最新告警在最前面。

可以隐患点名称、人员名称进行模糊查询；根据告警时间、告警次数范围筛选告警；根据告警等级、告警类型、警情状态下拉选择筛选告警。

下面显示分页栏，显示总页数、当前页号、每页显示条数、总条数等。

列表上面左侧显示筛选条件和查询按钮，右侧显示功能按钮，功能包括：反馈、误报、销警、导出，这些功能是批量操作，数据行尾操作列中的是单记录操作。

列表上单击告警事件，弹窗显示告警详情；点击告警次数弹窗显示所以得告警列表。

按需求实现前端功能，不开发后端接口；模拟数据以便展示相应的功能。

待办告警中查询条件，告警等级、告警类型和告警状态，可以支持多选，选中框长度调至120px。

# 告警判据管理
告警中心的告警判据模块，包括监测类型、隐患点两种导航方式：
1、监测类型：为每种监测类型设置四级告警判据，分别对应不同等级的告警；界面分为左侧监测类型选择器，右侧作为判据设置表单，参考的内容和样式；其中每个级别中分三种判据
   1）多指标判据，是一个编辑展示框，编辑框后面是一个修改按钮，点击修改按钮弹窗编辑判据，内容参考；
   2）告警持续时长，按监测周期次数，设置；
   3）静默数据周期，按监测周期次数，设置。
判据按照1、2、3、4的顺序排列，并内容默认显示第一个监测类型的判据设置表单。
示例监测类型数据是表面位移、深部位移、表面沉降、深部沉降、温湿度、加速度、土体含水率。

2、隐患点：为每个隐患点分组或隐患点设置告警判据管理；界面分为左侧隐患点分组选择器，右侧作为判据设置表单与监测类型判据表单内容相同，样式和内容请参考。

注意，只实现前端，如果需要后端数据，先模拟数据，给出效果。

AlarmCriteria.vue的指标判据编辑中，分为判据表达式编辑区，说明区和表达式元素区，三个区的关系说明如下：
1、判据表达式编辑区，是综合编辑判据表达式的区域，是本编辑器的主要工作区域，获得表达式元素区和键盘输入的内容生成判据表达式，用以告警判断；
2、说明区，是指标判据表达式，以人类更容易读取的方式描述判据表达式，主要是界面显示使用；
3、表达式元素区，显示此监测类型或隐患点，可以使用的元素和指标，当点击某一个元素或指标，将此元素或指标放于判据表达式编辑区，当前输入点位置。
请按上面的界面逻辑，保留当前界面布局，对界面功能进行重构。

# 历史告警需求
告警中心的历史告警，与待办告警模块相似，只是没有反馈、误报、消警、批量反馈、批量误报、批量消警功能，其他功能都有。
历史告警就是待办告警处置完成后，自动进入历史告警中；只支持查询能力和导出能力。


告警中心的告警状态有：新警情、已响应、已消警、误报 四种状态，其中模块需要有以下调整：
1、待办告警中，主要显示和处理新警情、已响应 这两种状态的告警事件，告警状态中只保留新警情、已响应两种状态，其他状态不显示；列表中也只显示这两种状态的告警事件。
2、历史告警中，主要查询误报、已销警这两种状态的告警事件；告警状态中只保留误报、已销警两种状态，其他状态不显示；列表中也只显示这两种状态的告警事件。
