# 首页需求
 首页是系统登录后第一个展示页面，它的代码实现是Dashboard.vue文件，路由是/dashboard；导航栏的图标指向此页面。
 它以地图为背景，形象的展示隐患点分布。
 技术上是利用leaflet地图库，结合vuegis插件，实现地图的展示和交互;调用天地图资源https://t0.tianditu.gov.cn/img_w/wmts 授权tk=8dda07d4649c77efd0537a0ff0a1df13
 支持地图的缩放、平移、旋转、添加图层等功能。

Dashboard.vue右侧增加面板，将图层选择、缩放按钮整体向左移，放于右侧面板左侧。

新增的面板内容，仿照综合视图的告警态势的内容和样式布局，并且面板可以隐藏和显示操作。


Dashboard.vue中图层选择和缩放工具按钮整体放于告警态势左侧，并随告警态势面板的隐藏而向右移动位置。

Dashboard.vue在地图组件中
1、首先按系统设置中关注范围，绘制关注的边界（边界用红色线条），并对不关注的范围加半透明蒙版，加强关注效果；
2、利用隐患点管理中隐患点资料，按中心点绘制隐患点；
3、鼠标移入隐患点，气泡方式显示隐患点信息--隐患点名称、坐标位置、所属分组、描述、绑定设备数等，移出，自动消失；
4、隐患点关联连的设备中有告警的，在隐患点图标，用水波纹的方式显示告警，水波纹颜色按告警级别分为红、橙、黄、蓝四种。

Dashboard.vue默认打开时，地图自动按系统关注区域中心放于屏幕中心，缩放层级调到地图显示区域。

Dashboard.vue默认打开时，地图层级再大一点；并去除天地图和组件leaflet的logo。

Dashboard.vue在缩放按钮下面，依次向下放置查询按钮图标、图层管理图标、图例说明图标，点击他们分别展开不同的功能，如下：
1、查询按钮图标，从图标左侧向左拉开一个编辑框和查询小按钮，可以输入隐患点名称，模糊查询，编辑框下部出现下拉列表，点击一个，地图漫游到地图上该隐患点位置，图标并闪缩；
2、图层管理图标，点击在图标左侧列出树状结构的图层控制项，包括地图的名称标注、水系图、道路图、隐患点分组、隐患点状态（监测中、停测和完结），默认显示监测中；
3、图例说明图标，从图标左侧向左展开，显示地图中隐患点图标及说明，还包括隐患点在不同状态下的图标和锁门，还包括报警状态图标及说明等。





 他是利用weggis技术，分两个层级，总览层和隐患点详细层；其中，总览层主要按照登陆角色权限，为用户提供系统总体态势，对整个系统情况可视化展示，帮助用户快速了解和决策；隐患点层，结合地图展示隐患点详细信息，直观展示各设备分布图。

# 页面框架头优化
管理员前面加一个系统消息功能，用图标表示，参考#主页头样例.png中样式；图标上显示实时的消息数量，点击弹窗显示系统消息列表。
消息列表中分为未读和已读消息，默认显示未读消息。

## 用户功能补全
管理员下来按钮中的基本信息和密码修改功能补全，都使用模态弹窗方式。
1、基本信息，包括用户名称，真实名称、联系电话、邮箱、所属组织、备注内容，参考身份管理的修改界面。
2、密码修改，包括旧密码、新密码、确认密码，参考重置密码的界面。

# 首页优化
1、首页布局改为以地图为展示背景，其他统计模块或功能都在地图上进行悬浮展示。
2、总览层和隐患点层，按地图操作进行体现，默认显示总览层，点击地图中的隐患点或设备，进入具体的隐患点层，关闭隐患点层，自动返回总览层。

# 首页优化2
1、去除总览层所在的容器；
2、系统健康度和资源统计的容器背景透明化；
3、右侧告警板块下移40像素，并背景使用半透明；
4、图层管理使用地图工具按钮样式，放于告警板块的左上部。
