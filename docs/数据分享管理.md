# 分享策略管理
报告报表下开发一个“共享策略”模块，管理系统成果数据向第三方系统、上下级单位等进行分享。参考设备管理页面/basic/device的结构，参考CompositeAlarm.vue的卡片风格，实现一个卡片列表管理模块；
共享策略是通过数据推送或接口服务等方式，向第三方或上、下级单位等进行基础数据、成果数据等分享。该模块主要是管理分享的授权管理、控制数据分享方式、数据范围、频率等，保证分享安全有效。其他细节需求如下：
1、共享策略的主要内容：编号、名称、描述、方式、地址（ip或ip+端口）、主题、账号、密码、其他参数、范围、频率、状态、成功分享量、创建时间、更新时间。
2、共享策略的方式：统一化数据推送方式、定制化数据推送方式、统一化数据服务、定制化数据服务四种方式。
注意:统一化数据推送和统一化数据服务是固定了数据项和分享模型的方式，不支持个性化定制；定制化数据推送和定制化数据服务是以可视化的(bLockly)编程，灵活的定制分享模型。
3、共享策略需要支持查看运行日志。
4、定制化策略需要支持可视化编程(bLockly)，并且需要提供多种预置工具方法(比如:监听/订阅数据包或其他策略解析，查询设备、厂家、隐患点信息，调用策略属性、算法(多种python算法)、存储数据、数据输出等)。
5、共享策略需要支持设置共享数据范围(隐患点分组、隐患点、厂商或设备等)。
