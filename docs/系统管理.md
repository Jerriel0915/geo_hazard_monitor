# 组织管理
支持最多 5 级组织架构管理，实现数据权限隔离，是系统权限与数据范围的基础单元。
## 属性
### 字段
组织 ID、名称、父 ID、负责人、电话、地址、状态、区域(及中心)
### 层级
最多 5 级
### 数据权限
本组织及下级可见，可查看上级分享数据
## 功能
### 组织增删改查、层级调整
组织增删改查、层级调整
### 组织负责人与联系方式维护
组织负责人与联系方式维护
### 组织状态启用 / 禁用
组织状态启用 / 禁用
### 数据范围自动隔离
数据范围自动隔离
## UI 参考
### 组织树状列表
层级展示、拖拽调整
### 组织详情弹窗
完整字段编辑
### 数据范围说明提示
## 逻辑描述
### 按父 ID 构建多级树形结构，最深 5 级
### 用户登录按所属组织过滤数据范围
### 上级组织可查看下级，下级不可查看上级非共享数据
### 组织禁用后，关联用户与设备不可操作


# 身份管理
系统用户账号、登录、密码、Token 全生命周期管理，保障身份安全。

## 属性
- 登录方式：账号密码 + 验证码
- 密码加密：BCrypt
- Token：2 小时过期，支持刷新
- 账号状态：正常 / 禁用 / 锁定 / 过期
## 功能
- 用户登录、登出、Token 刷新
- 账号创建、启用、禁用、锁定
- 密码加密存储与重置
- 登录异常检测
## UI 参考
- 登录页：账号、密码、验证码输入
- 用户管理列表：状态、账号、姓名、组织
- 密码重置弹窗
## 逻辑描述
- 登录校验通过后生成时效 Token
- 密码全程 BCrypt 加密，不存明文
- Token 过期自动拦截，需重新登录 / 刷新
- 异常登录自动锁定账号

# 权限管理
基于 RBAC 模型实现细粒度权限控制，覆盖菜单、按钮、数据、接口四级权限。
## 属性
- 模型：RBAC
- 粒度：菜单、按钮、数据范围、接口
- 角色：超管、管理员、值班员、巡检员、只读
## 功能
- 角色创建、配置、分配
- 菜单 / 按钮权限勾选
- 数据范围权限配置
- 接口权限控制
## UI 参考
- 角色列表 + 权限配置面板
- 菜单树勾选、按钮权限勾选
- 数据范围选择器
## 逻辑描述
- 用户→角色→权限三级绑定
- 接口请求统一校验权限
- 前端按权限动态渲染菜单与按钮
- 超管拥有全部权限，不可删除
# 日志管理
全系统操作行为审计记录，留存可追溯，支持导出。
## 属性
- 记录类型：登录、增删改、导出、告警处置、参数配置
- 保留时长：≥1 年
- 导出格式：Excel
## 功能
- 日志自动记录与存储
- 多条件查询日志
- 日志导出
- 日志定期清理
## UI 参考
- 日志列表：类型、用户、时间、内容、IP
- 筛选器：操作类型、用户、时间范围
## 逻辑描述
- 关键操作统一拦截写入日志
- 日志不可修改、不可删除
- 到期自动清理，保留≥1 年
- 按权限控制日志查看范围


# 系统设置

作为系统全局策略配置中心，统一对告警规则、通知机制、数据清理策略进行集中管控；主要包含系统参数配置、告警分发规则维护、数据清理周期设置等功能。
## 系统参数
涵盖系统名称、数据保留时长（超期自动清理）、单一隐患点直接进入、等全系统配置项，本参数管理模块为全局性配置中心，主要作为系统全局枚举与公共参数的统一维护、修改入口。
### 属性
- 记录：参数id、参数编码、分类名称、参数名称、参数值、备注、创建时间、作废、作废时间。
### 功能
- 参数由系统研发确定，此功能只做修改。系统管理员只能做修改，没有新增、删除等权限。只有修改保存功能。
### UI 参考
- 作为长表单方式，按照分类名称为分类面板，参数名称为标签、值为编辑框。
- 表单式修改，点击保存

### 逻辑描述
- 左侧是类型列表，可以帮助右侧长表单快速定位
- 右侧长表单滚动条也可以自由向下翻动
- 保存后，通知各个识别模块重新加载参数进行界面或运行更新。

## 告警分发
立足于系统全局层面，对隐患点监测告警、设备离线等各类消息通知规则进行统一编制与集中管理。该模块规则与单一隐患点的个性化告警分发规则相互呼应、互为补充，支持隐患点批量隐患点配置，大幅提升规则管理效率。
### 属性
- 记录：规则id、隐患点ID、类型（告警、离线）、等级（设备）、人员、渠道、执行时间、备注、创建人、创建时间、修改人、修改时间、作废、作废时间、删除、删除时间。
### 功能
- 新增：按隐患点，进行循环存入配置信息。
- 编辑：只能对隐患点一个一个的修改配置信息。
- 删除：可以批量或单个删除，进行逻辑删除。
- 作废/恢复：暂停使用此规则，可以批量操作。
- 查询：支持隐患点名称模糊、状态（下拉列表）、类型（下拉列表）、渠道（下拉列表），进行筛选。
- 导入/导出：对查询结果进行导出，支持所见即所得；按固定导入模块进行导入（尽量参考导出结果样式）。
### UI 参考
- 以表单管理为主。
- 新增和编辑都是新开弹窗表单进行处理。

### 逻辑描述
- 此模块提供告警规则处理，修改后通知告警通知模块进行识别读取。
- 离线通知规则，修改后通知离线消息调度模块进行识别读取。
- 没有设置规则时，不进行通知；可以在部署环节考虑预置通知规则。
